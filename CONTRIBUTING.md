# Contributing to mdPad

Thank you for your interest in mdPad. This repository is currently maintained as proprietary
software rather than as an open-source project.

Bug reports and focused feature suggestions are welcome through GitHub Issues. Please include the
mdPad version, Windows version, clear reproduction steps, expected behaviour, actual behaviour,
and screenshots when they help explain the problem. Never attach private Markdown documents or
other sensitive files.

Code contributions require prior agreement with the maintainer. Contact mdpad@olynors.com before
preparing a pull request.
